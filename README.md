# Finn Jensen — Engineering Portfolio

A static portfolio designed for GitHub Pages.

## Publish it
1. Create a public GitHub repository named `YOURUSERNAME.github.io`.
2. Upload everything in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under the publishing source, choose the `main` branch and `/ (root)`.
5. Your site will be available at `https://YOURUSERNAME.github.io/`.

## Before applying to internships
- Replace placeholder project media with real photos/CAD renders.
- Upload your current resume as `assets/Finn_Jensen_Resume.pdf`.
- Update the LinkedIn and GitHub links in `index.html`.
- Add actual project dates and your exact tools/skills.
- Keep the site focused on engineering work and measurable results.
